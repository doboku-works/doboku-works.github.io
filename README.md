# doboku-works.github.io — 土木 3D/4D ＆ インフラ可視化 技術デモアーカイブ

土木工学・施工計画・構造力学 FEM と WebGL（Three.js）を組み合わせた、個人の技術検証・デジタルアート公開用の完全静的サイト（GitHub Pages）です。

- **公開サイト**: https://doboku-works.github.io/
- 掲載しているすべての 3D モデル・地形・構造物諸元・力学データは、技術検証および個人公開のために独自設計した**完全架空のオリジナルモデル**です。

## 収録デモ（すべてブラウザで直接 3D 操作可能）

1. **TOKYO UNDERGROUND — 都市地下解剖キューブ・ジオラマ** (`works/urban-cube/viewer/`)
2. **新青葉川橋 — 少数鈑桁橋（合理化2主桁・合成床版）送り出し架設 4D ＆ FEM** (`works/bridge-launching/viewer/`)
3. **大沢川砂防堰堤 — 基準準拠 施工計画・段階水替え・打設割 3D/4D** (`works/sabo-dam/viewer/`)
